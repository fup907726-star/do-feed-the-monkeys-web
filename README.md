# do-feed-the-monkeys-web

手机可测的网页原型。先出 3F home 住处，再坐进靠窗木桌的观察环。

## 测什么

1. 等轴 3F 房间（对照 Linear「主角住处图」）：灰混凝土、暖黄吊灯、西窗木桌、北侧低床、右下楼梯井
2. 点桌子进入灰窗社观察单 GW-OBS-001（周凯 / 顺达物流）
3. 切三路监控、推进时间、可选轻喂、交差
4. 可站起来回房间。楼梯 / 院子仍不下
